## 📚 Danh mục Nội dung

### 1. `01_python_mastery_basics.py`
- Cú pháp chuẩn Pythonic (PEP 8)
- Quản lý bộ nhớ, Kiểu dữ liệu nâng cao
- Handling Exceptions đúng cách (không nuốt lỗi `except Exception: pass`)
- Context Managers (`with`) & Resource Leak Prevention

### 2. `02_python_thinking_architecture.py`
- **Tư duy Kiến trúc Code (Software Architecture)**
- Nguyên lý **SOLID** áp dụng vào Python
- So sánh **Bad Code** (Code rối, khó mở rộng) vs **Clean Code** (Dễ bảo trì, dễ test)
- Các Design Patterns thông dụng: Singleton, Factory, Strategy

### 3. `03_python_debugging_and_fixing.py`
- **Tư duy & Quy trình 5 bước Fix Bug chuyên nghiệp**
- Sử dụng `logging` thay thế `print()`
- Phân tích `Traceback` và xác định Root Cause
- Kỹ thuật Debugging với `pdb` / `breakpoint()`
- Viết **Unit Test** với `unittest` để phòng ngừa regression bug
